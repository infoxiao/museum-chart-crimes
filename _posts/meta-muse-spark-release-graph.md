The problem is not subtle: the chart uses color to spotlight Meta's own model even though it is not the best-performing one on the graph.

That flips the visual takeaway. Readers are trained to treat the highlighted series as the winner, so coloring Muse Spark instead of the top result makes the eye land on the house model first and the actual ranking second.

If the point is that Muse Spark is competitive, say that in the caption and keep the comparison neutral. If the point is that one model leads, then the leading model should get the emphasis.
